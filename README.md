# 아이돌봄 비서

맞벌이 부부가 아이돌봄서비스를 쓰려면 매달 같은 준비를 반복해야 합니다. 가정통신문에서 준비물과 제출 서류를 골라 적고, 부부 출퇴근과 아이 등하원 사이에 비는 시간을 계산하고, 아이돌봄 누리집에서 날짜마다 시간을 넣습니다.

아이돌봄 비서는 이 준비를 대신합니다.

1. **가족 일정**: 부부 근무 시간과 아이별 어린이집·학교·학원 시간을 넣습니다.
2. **가정통신문**: 붙여 넣은 통신문에서 준비물, 제출 서류, 행사, 등하원 변경을 날짜와 함께 뽑고 전날 저녁과 당일 아침 알림 일정을 만듭니다.
3. **아이돌봄 신청표**: 부부가 모두 집에 없고 아이가 기관에도 없는 시간을 30분 단위로 계산해, 아이돌봄 신청 규칙(1회 최소 2시간, 06시부터 22시, 두 아이 같은 시간은 동시돌봄)에 맞춘 신청표를 만듭니다. 주말과 공휴일은 뺍니다.
4. **함께 보기**: 부부 공유 캘린더(.ics), 신청표 파일(.json, .csv), 예상 본인부담금.

## 계산 규칙
- 돌봄 공백 = 하루 돌봄 범위에서 기관에 있는 시간을 빼고, 부모 중 한 명이라도 집에 있는 시간을 뺀 나머지
- 부모가 집에 없는 시간 = 근무 시작에서 이동 여유를 앞당기고 근무 끝에 이동 여유를 더한 구간
- 기관과 기관 사이의 짧은 공백(기본 60분 미만, 학교에서 학원으로 걸어가는 시간 등)은 신청하지 않음. 등원 전과 하원 후 공백은 짧아도 신청
- 2시간이 안 되는 공백은 기관 시간과 겹치지 않는 쪽으로 늘림(등원 전 공백은 더 이른 시각으로)
- 같은 입력이면 항상 같은 결과(시험 `node engine.test.mjs`, `node notice.test.mjs`)

## 데이터
- `holidays.json`: 공휴일 기본값. 출처 date.nager.at 공개 공휴일 자료(대한민국 2026, 2027). 아이돌봄 신청 달력의 빨간 날이 최종 기준이며 화면에서 고칠 수 있습니다.
- 시간당 본인부담금은 가정마다 정부지원 유형과 할인이 달라 기본값을 두지 않습니다. 아이돌봄 누리집 이용요금 안내나 지난 신청 내역의 금액을 넣으세요.

## 개인정보
계산은 브라우저 안에서만 합니다. 입력한 가족 정보는 이 브라우저의 저장소에만 남고 어디에도 보내지 않습니다. 화면의 예시 가족은 가상입니다.
